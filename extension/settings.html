Using local Ollama? Fix the 403 Forbidden first

By default Ollama refuses requests from a browser extension, so ChatPanel gets 403 Forbidden. Start it so it accepts extension origins: 

OLLAMA_ORIGINS="chrome-extension://*" ollama serve

This allows browser extensions only — safer than "*", which would let any website you visit reach your local Ollama. To lock it down further, use this extension's exact id from chrome://extensions: OLLAMA_ORIGINS="chrome-extension://<id>".

Keep that terminal running, then set Base URL http://localhost:11434/v1 and click Load models. The API key can be left blank.

Notes are encrypted on your device and searchable alongside your chats and meetings. These preferences apply to the notes editor and its AI commands.

Co-writer — a small model team that drafts, fixes & researches as you write

When on, an editor fixes typos/grammar on a pause, a researcher surfaces related material, and a writer drafts ahead on ⌘↵. Off by default — it makes model calls as you type. Pick a model per role from the team button in the note editor's footer.

Inline autocomplete — as-you-type ghost suggestions, Tab to accept

On a short typing pause at the end of a note, a model predicts the next few words and shows them as grey ghost text — press Tab to accept, Esc or keep typing to dismiss. Off by default (it calls a model as you write). Accepted text is attributed to the model in the note's history.

Privacy & Gateway — what leaves this device, and in what shape

Three layers, each configurable on its own. Redaction changes what a model sees; the data boundary decides whether a page may be sent at all; the gateway is an optional local process that adds on-device models and applies the same rules to tools outside the extension.

Privacy Gateway — a local process that extends all of the above checking…

Connection — a small process on your machine, free & open-source

The ChatPanel Gateway runs on-device models (speech-to-text, PII detection) and puts the same redaction in the middle of tools outside the extension: point OpenCode / Pi at it and it drives Codex or Claude Code behind your subscription login (via the bridge), redacting on the way out and restoring in the reply.

Not connected.

Only needed for older gateways. Find it in ~/.chatpanel/gateway-token (macOS/Linux) — or just update the gateway and it authorizes automatically.

What the gateway adds — all on your machine, once it's running:

  • 🎙 Local speech-to-text — dictate into ChatPanel with a Whisper model you choose & download; your audio never leaves your machine.
  • 🛡 Local PII detection (NER) — the names / orgs / locations detector; pick from downloadable multilingual & de-identification models.
  • 🔀 Model routing — send OpenCode · Pi · aider through your Codex / Claude Code login via the bridge, redacted on the way out and restored in the reply.
  • 🔎 Full-history search — index your chats & meetings locally so on-device agents can search your whole corpus.

Free & open-source. Install it with the commands below, then this section manages all of it.

Base URL : http://127.0.0.1:4320/v1

Model routing — which model would answer, and why

Routing is a rule, not a model call: your models’ declared reach, capability, cost and latency go in, a decision and its reasons come out — instantly and for free. Privacy and capability eliminate candidates; cost and latency only order what survives, so a cheaper model can never outrank a privacy requirement. It currently observes only: every turn records what it would have chosen, visible in Activity, while your selected agent still answers.

Try a request — describe one and see what Auto would choose for it, and why. These controls are a test: they change nothing. A real turn's needs come from the turn itself — the tools it carries, how long it is, whether it involves a page or a spreadsheet.

What each model is — facts, not preferences. These describe the models; the rules above decide which one a turn needs. Both feed every decision. ChatPanel guesses each model’s cost, speed and abilities from its name and URL. Those guesses are often right and sometimes wrong — correct them here and routing follows what you say. Nothing here is a one-way door: every control keeps its detected value on the list, and Reset puts a whole row back. Reach can only be moved outward of what was detected: you can tell us a local-looking endpoint really goes out, but not that a cloud one is on your device.

Plugins — everything ChatPanel loads, and what you can switch off

Adapters drive an app through its own data format instead of clicking at pixels. Tool groups are the sets of tools offered to the model each turn. Switching one off takes effect on your next message — no reload needed — and a disabled group is never built, so it costs nothing, not even the time it would spend connecting. Security is required and cannot be turned off.

Preferences

Runs after chats or meeting transcripts change, then saves concise graph topics locally. Blank uses the active model/agent.

As you pause typing, a model suggests a short continuation — press Tab to accept. For this to feel instant it needs a small, fast API model (e.g. a 1–3B model on your local Ollama / llama.cpp) — set it as an endpoint's “Autocomplete model” below. Local CLI agents spawn a process per request (~seconds), so they’re too slow for inline autocomplete. Avoid reasoning models — they “think” instead of completing.

Where the agent may fill forms, click, and draw. Ask shows a one-click offer in the composer when you open an app ChatPanel knows how to drive (Excalidraw, draw.io, tldraw) — nothing is armed until you accept, and the answer is remembered per site. Every readable tab is the older behaviour and stays available; it also arms on your bank and your email, so prefer Ask.

When Act on page is on, ask for your OK before the agent fills a form, clicks, or types — so a web page, meeting transcript, or connected tool can’t quietly steer it into acting for you. Pick Allow for this site to stop being asked on a site you trust. On by default.

When the agent acts on a page ( Act on page), use trusted browser events instead of synthetic ones — far more reliable on heavy web apps like Google Flights, and required for anything that works by coordinates rather than form fields: canvas apps, drawing, games, and keyboard-driven controls. Chrome shows a “ChatPanel is debugging this browser” banner while the agent is acting; it goes away a few seconds after it stops. On by default (it only ever applies once you’ve turned Act on page on). Turn it off if you keep DevTools open on the pages you automate — the two can’t attach at the same time. Chromium browsers only; elsewhere ChatPanel falls back automatically.

For developers and power users. Lets the agent read an app’s real state or install a fast in-page loop for real-time apps — far more precise than clicking and looking. This is the most powerful thing you can grant: page JavaScript can read and change anything on that page that you can, as you. ChatPanel asks you to approve every single call and shows the exact code — that prompt cannot be turned off or waived with Allow for this site. Requires High-reliability page control. Off by default.

Heads up: acting on the page is best-effort automation driven by an AI model — it can pick the wrong field or misread a layout, and content it reads (web pages, meeting transcripts, connected tools) can try to influence it. Keep Confirm before page actions on for anything that matters and review each action before you allow it — especially on banking, email, or work accounts. You stay in control: ChatPanel only acts when you turn this on and ask.

Back up & restore your data Pro

Back up everything — your settings (API endpoints & keys, agents, MCP servers, skills, preferences), endpoint sign-ins, all chat history and all captured meetings. All new backups are compressed and encrypted locally before they are saved to Downloads or sent to your Google Drive. Your Pro license isn’t included.

Restore an encrypted file on a fresh install on another machine to bring your whole setup across, or restore from Drive to merge chats, meetings, and notes while keeping that device’s settings and sign-ins.

Encrypted backups

Keep a copy of all your data outside the extension so a reinstall cannot lose it. Choose local Downloads, your Google Drive, or both. ChatPanel compresses first, encrypts locally, and rotates seven weekday files per device. Google receives only ciphertext and never receives your backup password.

Give each browser profile a recognizable name. Every device gets its own seven rotating Drive slots, so one machine never overwrites another machine’s backups.

The password is encrypted with a device-local key and stored only inside this browser profile so scheduled backups can run unattended. It is never synced or uploaded. Restore on another machine by connecting the same Drive account and entering the same password. There is no password recovery; anyone controlling this unlocked browser profile can run its configured backups.

Google Drive

No Google developer setup is required. Connect once to your own Google account; ChatPanel securely refreshes authorization for scheduled backups on this browser. The callback is tied to this installed browser build.

Drive restore downloads ciphertext into memory and decrypts it with the backup password above. It always merges chats, meetings, and notes. API keys, OAuth sign-ins, gateway configuration, and other device settings stay local. No temporary backup file is saved.

Browser download setting: for Chrome or Edge, open the browser's Downloads settings and turn off “Ask where to save each file before downloading.” This is required only for Local or Both; Drive-only never invokes Downloads and never shows a file prompt.

“Back up now” always creates an encrypted backup using the destination and password above. Existing legacy ChatPanel ZIP exports can still be restored.

Automatic schedule

Pick one local time. ChatPanel writes at most one completed automatic backup per calendar day. If Chrome was closed then, the next browser start catches up only after the selected hour and only when today’s backup has not already completed. “Back up now” is an explicit one-off.
